# Relative collision spectrum with exterior packets

## 1. New theorem target

The current evidence distinguishes two problems that must not be conflated.

For an isolated ordered cluster of size \(m\), the corrected moment block has the consecutive local spectrum expected from the simplified model. The observed missing grade appears only after the cluster is embedded in a larger configuration containing at least one separated packet.

This suggests that the relevant invariant is not the intrinsic Smith spectrum of the cluster block, but the relative Smith spectrum of the cluster after quotienting by the target image of the exterior variables.

The theorem target is therefore:

\[
\textbf{Relative spectrum conjecture.}
\]

Let an ordered cluster of size \(m\) collide at scale \(h\), while \(n\ge 1\) exterior nodes remain separated from the cluster and from one another. After eliminating the exterior source variables and passing to the cluster Schur complement, the cluster contribution has exponent set

\[
E_m^{\mathrm{rel}}
=
\{0,1,\ldots,m-1,m+1,\ldots,2m-1\}.
\]

By contrast, the isolated cluster block has the consecutive exponent set predicted by its intrinsic corrected-moment matrix.

This document records the mechanism to test. It does not claim the conjecture is proved.

## 2. Block form

Write the full Jacobian in cluster/exterior source coordinates and a compatible target splitting as

\[
J(h)
=
\begin{pmatrix}
A(h) & B(h)\\
C(h) & D(h)
\end{pmatrix},
\]

where \(A(h)\) is the cluster block and \(D(h)\) is the exterior block. On the separated stratum, \(D(0)\) is expected to have full rank in the exterior directions.

The relative cluster map is represented by the Schur complement

\[
S(h)=A(h)-B(h)D(h)^{-1}C(h),
\]

or, invariantly, by the cluster columns modulo the target span of the exterior columns.

The simplified isolated calculation studied only \(A(h)\). If the gap occurs in \(S(h)\) but not in \(A(h)\), then the missing grade is an embedding effect.

## 3. Candidate absorption mechanism

The exterior nodes contribute target directions generated by their value and position columns. These directions may absorb one leading cluster jet after elimination.

The numerical pattern suggests that the absorbed direction is the grade-\(m\) cluster jet. In a derivative-jet frame centered at the collision point, this means that the leading vector associated with \(M^{(m)}(c)\) becomes dependent modulo the exterior target image, while the higher cluster jets survive.

Equivalently, the first upper determinantal divisor of the relative block gains one additional power of \(h\):

\[
(m,m+1,\ldots,2m-2)
\longmapsto
(m+1,m+2,\ldots,2m-1).
\]

The total valuation increases by \(m-1\). This must be visible in the minors of the Schur complement, not merely in an unweighted row relation.

## 4. Immediate falsification tests

The hypothesis makes two sharp predictions.

### Exterior multiplicity

Run the same cluster with

\[
n=0,1,2,3
\]

separated exterior packets.

Expected behavior:

- \(n=0\): no missing grade;
- every \(n\ge1\): the same single gap at \(m\).

If the gap changes with \(n\), then the mechanism is not a single absorbed target direction.

### Exterior displacement

Fix \(n\ge1\) and vary the exterior locations from moderately separated to very far from the collision center.

Expected behavior:

- the coefficients and conditioning may change;
- the valuation pattern should remain fixed while the exterior block stays nondegenerate;
- the gap should change only when an exterior node approaches another singular stratum.

This would show that the phenomenon is algebraic and relative, not a metric effect caused by distance.

## 5. Rank formulation

Let \(E\) denote the target span of the exterior columns at \(h=0\), and let

\[
\pi_E:Y\to Y/E
\]

be the quotient map. The relative cluster matrix is

\[
J_{\mathrm{rel}}(h)=\pi_EJ_{\mathrm{cluster}}(h),
\]

up to analytic invertible changes induced by the exterior block.

The missing-grade claim becomes:

1. lower cluster roots of orders \(0,\ldots,m-1\) remain independent in \(Y/E\);
2. the order-\(m\) upper leading vector lies in \(E\);
3. the order-\(m+1\) through order-\(2m-1\) leading vectors are independent modulo \(E\).

This is the rank statement that a proof should establish.

## 6. Relation to the corrected isolated model

The earlier obstruction is now useful rather than damaging. It proves that the isolated corrected-moment block generically contains grade \(m\). Therefore any valid proof of the observed gap must use data outside that block.

The relative hypothesis identifies exactly where that data enters: the exterior target image and its Schur complement.

Thus the corrected isolated result and the embedded numerical result are compatible:

\[
\text{intrinsic cluster spectrum}
\neq
\text{relative embedded spectrum}.
\]
